# PHP IDE Plugins

Plugins para o PHP IDE, mantidos por [Jeidison Farias](https://github.com/jeidison).

## TODO Hints

O plugin em `plugins/todo-hints` destaca TODO/FIXME, mostra a contagem no editor e sugere responsáveis a partir de `.todo-owners`.

### Instalar

1. Baixe ou clone este repositório.
2. Na IDE, abra **Aparência → Plugins… → Instalar pasta**.
3. Selecione `plugins/todo-hints` e revise a permissão `project.read`.
4. Abra um arquivo PHP, Blade ou Markdown com `TODO: revisar`.

A leitura de `.todo-owners` depende da permissão. Diagnósticos e contagem funcionam sem ela. Consulte o README do plugin para detalhes.
